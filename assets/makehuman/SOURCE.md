# MakeHuman base mesh

Downloaded 2026-10-13 from the MakeHuman 1.x source repository (makehumancommunity/makehuman, branch master):

- `base.obj`: makehuman/data/3dobjs/base.obj (the default human; units are decimetres, 1.67 m tall)
- `default.mhskel`: makehuman/data/rigs/default.mhskel (the default 163-bone rig)
- `default_weights.mhw`: makehuman/data/rigs/default_weights.mhw (its skin weights; the file itself says "license": "CC0")

Licence: CC0. MakeHuman's FAQ "Are MakeHuman files free?"
(https://static.makehumancommunity.org/makehuman/faq/are_makehuman_files_free.html) says "The asset license is CC0",
and "What changed regarding the license in 2020?"
(https://static.makehumancommunity.org/oldsite/faq/what_changed_regarding_the_license_in_2020.html) says "Targets,
proxies and the base mesh are considered graphical assets, covered by CC0". (The MakeHuman program code is AGPL;
none of it is used here.)
