# ANSUR II (2012 Anthropometric Survey of U.S. Army Personnel), public data

`ergonomics.csv`: the ANSUR II public data (6068 soldiers: 4082 men, 1986 women; one row per person, measurements
in mm), as mirrored by calmcode.io (https://calmcode.io/datasets/ergonomics, file
https://calmcode.io/static/data/ergonomics.csv), downloaded 2026-10-15. The Penn State OPEN Lab links
(https://www.openlab.psu.edu/datasets/ansur2/) no longer serve the CSV files.
Reference: Gordon CC et al. (2014). 2012 Anthropometric Survey of U.S. Army Personnel: Methods and Summary
Statistics. U.S. Army Natick Soldier RD&E Center, Technical Report NATICK/TR-15/007.
Used only as a size guide (men's means: wrist 17.6 cm, ankle 22.9, neck 39.8, forearm flexed 31.0, calf 39.2).
